# Netflix Data Analytics Pipeline

## What I Built

I built this project to analyze Netflix content data from 2008 to 2021. 
I used Python to clean the data, stored it in an SQLite database, and 
built an interactive dashboard using Streamlit.

## What It Does

- Shows Movies vs TV Shows breakdown
- Top 10 countries producing Netflix content
- Yearly content addition trends
- Explore content by type, country, and year

## Tools Used

- Python & Pandas – data cleaning
- SQLite – storing data
- Matplotlib – charts
- Streamlit – dashboard

## Dataset

Netflix Titles dataset from Kaggle – 8,807 rows (2008–2021)

## What I Learned

This project taught me how to build a complete data pipeline 
from raw CSV to a live dashboard — handling messy data, 
writing SQL queries, and connecting everything in one project.
